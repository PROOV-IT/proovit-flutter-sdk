# PROOV-IT private Flutter Capture SDK

This private repository contains the versioned Android-only Flutter plugin at its root and a partner integration app/backend under `examples/`. Start with [`proovit_capture/README.md`](README.md), then use the [public developer guide](https://admin.staging.proov-it.online/developers/sdk).

Request repository read access from your PROOV-IT contact. No public pub.dev or Maven artifact is provided.
